    Troubleshooting

    Why won't my video play?

    Unsupported codec

    The browser can't decode the video or audio stream. FISOMOVIE PLAYER uses WebCodecs + FFmpeg WASM to handle HEVC, AV1, and more.

    Black screen or no audio

    Often a codec inside the container (e.g. AC3, DTS). The player decodes these in software, so audio tracks should appear.

    CORS error

    The remote server blocks cross-origin reads. Use a same-origin URL or a CORS-enabled host.

    Expired or invalid URL

    Signed links time out. Re-copy the direct media URL and try again.

    HLS playback fails

    Needs a valid .m3u8 manifest with CORS headers. Some DRM streams won't work.

    Subtitles missing

    Embedded subtitles (SRT, ASS, PGS) are read directly from the file. External .vtt files can be loaded from the player menu.

    Buffering / stutter

    Slow network or oversized file. Try a lower-bitrate source or pause to buffer.
