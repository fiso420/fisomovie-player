      Capabilities

      Built for real-world video

      Everything below runs entirely in your browser. No uploads, no transcoding server.

      Broad format support

      MP4, MKV, WebM, MOV, TS, AVI and adaptive HLS / DASH streams — handled by FFmpeg WASM demuxing plus WebCodecs decoding.

      Multi-track playback

      Switch between embedded audio tracks and subtitle tracks when the media file provides them. External subtitles are supported via standard <track> markup.

      Privacy by design

      Local files are decoded on your device. Nothing is uploaded. Object URLs and player instances are cleaned up when you switch media.

      Professional controls

      Play/pause, seek, buffered progress, volume, playback speed, fullscreen, Picture-in-Picture, keyboard shortcuts and touch gestures.

      Adaptive streaming

      HLS (.m3u8), MPEG-DASH (.mpd) and Smooth Streaming are unified through Shaka Player with quality and track switching intact.

      HDR & 4K ready

      Detects and renders BT.2020 / PQ / HLG content on supported displays via WebGL2. Falls back to tone-mapped SDR elsewhere.

      Help

      Troubleshooting

      Quick checks for the most common playback problems.

      Unsupported codec / black screen

      Your browser or device may not expose a decoder for that codec. Try Chrome or Edge on desktop, or check whether the file uses HEVC or AV1 that your hardware cannot decode. A compatibility message appears instead of a blank player.

      No audio

      Check the volume and mute controls. If the file has multiple audio tracks, open the player track menu and select the correct one. Some containers store audio in a codec your browser cannot decode.

      CORS / remote URL fails

      A remote server must send Access-Control-Allow-Origin headers and support HTTP Range requests. Hotlink protection and signed URLs can also block playback. Local files never have this problem.

      Buffering / stutter

      High-bitrate 4K or 8K files may exceed what your device can decode in real time. Lower the playback speed, close other tabs, or use a lower-resolution source. Network speed also matters for remote URLs.

      HLS / DASH stream won't play

      Confirm the manifest URL ends with .m3u8 or .mpd and that the host allows CORS. Mixed content (HTTP media on an HTTPS page) is blocked by browsers.

      Subtitles missing

      Embedded subtitle tracks appear in the player menu when the file contains them. For external subtitles, the file must be loaded through the player's subtitle picker or a <track> element.

      Questions

      Frequently asked

      Are my local videos uploaded anywhere?

      No. Local files are read directly by your browser and decoded on your device. FISO VDO PLAYER has no upload endpoint and does not transmit local media to any server.

      Does it work on iPhone and iPad?

      Yes, with limits. Safari 18+ exposes WebCodecs, but codec support depends on the device and iOS version. Local file selection works; folder selection may not be available in Safari. HLS streams are the best-tested remote format on iOS.

      Why does a remote MP4 sometimes fail?

      Remote playback depends on the media host. It must allow cross-origin access, support range requests for seeking, and not require authentication. A direct URL that works in a browser tab may still be blocked for a player due to CORS.

      Can I play DRM-protected content?

      The player engine has optional Widevine / PlayReady / FairPlay support, but it requires a licence server and is not configured in this free deployment. DRM streams will show a clear "protected video" message instead of playing.

      Is there a file size limit?

      There is no hard limit, but very large 4K/8K files need enough device memory and a fast enough decoder. The player buffers ranges rather than loading the whole file at once.

      Can I use this on my own website?

      Yes. The player engine is Apache-2.0 licensed. Keep the attribution notice in the About / Credits area and respect the licence terms. The FISO branding and this UI are yours to adapt.
